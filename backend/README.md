# Project Governance — Backend

Rust/Axum GraphQL backend for Project Governance, built on the PDS App
Framework. The framework's `appfw_runtime` provides the request pipeline, auth,
data-access layer, policy evaluation, and observability; `appfw-provider-postgres`
provides the PostgreSQL provider. Both are consumed as pinned path dependencies
on the sibling `../app-framework` checkout (see the repository root README).

## Layout

| Path | Ownership |
|---|---|
| `src/services/` | Product — gate/workflow engine, governed Microsoft Graph provider, AI extraction. |
| `src/handlers/<schema>/<entity>.rs` | Product — custom method implementations; delegate to services. |
| `src/platform/` | Product — thin wiring over `appfw_runtime` (bootstrap, config, GraphQL gateway shell). |
| `src/routes/`, `src/schemas/`, `src/handlers/**/generated.rs`, `src/operations/` | Generated by `app_gen` from `.appfw/model/**`. Do not hand-edit; change the model and regenerate. |
| `src/data/` | Product — orchestration over the framework's `DataAccess`; `data/clients/postgres/` holds thin adapters over `appfw-provider-postgres`. |
| `config/` | Runtime configuration (data sources, environments). |
| `product_dist/` | Frontend SPA bundle, built by `cd frontend && npm run build`. Served at `/` when `APP_PRODUCT_UI_ENABLED=true`. |

## Feature flags

`default = ["http", "provider-postgres"]`. `mcp` / `kafka` / `sync` are not
enabled — this product runs a single HTTP process against one PostgreSQL data
source.

## Run

```bash
# database
docker compose -f ../podman-compose.yml up -d postgres

# backend on http://127.0.0.1:8080
cargo run -p backend
```

GraphQL routes are schema-specific: `/governance` (product) and `/system`
(framework metadata).

## Regenerate after a model change

```bash
# from the repository root; on Windows use the rust-appfw container (see root README)
scripts/appfw product validate --json
scripts/appfw product generate
scripts/appfw product generate --check --json
cargo check --workspace --all-targets && cargo test --workspace
```
