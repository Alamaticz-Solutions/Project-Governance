# Project Governance Portal - System & Workflow Documentation

This document serves as a comprehensive overview of the **Project Governance Portal**, detailing the workflows, system architecture, and features we have built to date.

## 1. System Overview
The Project Governance Portal is an enterprise-level workflow engine designed to seamlessly manage the lifecycle of project proposals—from conception through various review gates, and finally to executive alignment and investment approval.

- **Frontend Environment:** Angular-based application with a fully modernized, premium, and professional UI. It uses dynamic routing, role-based access control (RBAC), and interactive dashboards.
- **Backend Environment:** FastAPI-driven API serving as a sequential state machine. It manages structured approvals, roles, real-time stage transitions, and notification dispatching.

## 2. Core Governance Workflows
The sequential workflow has been carefully modularized and database-driven (replacing local storage mocks) to track the exact historical state and current owner of each project.

### Phase 1: Intake & Submission
- **4-Step Intake Wizard:** A modern, streamlined wizard allowing business users to propose new projects, capturing metadata, objectives, and initial justifications.
- **Direct-to-BTA Routing:** Automates the transition of ideas submitted by business users directly into the **BTA Review Stage**, bypassing unnecessary manual admin routing.

### Phase 2: Business Technology Alignment (BTA) Review
- **Dedicated BTA Inbox:** BTA reviewers get customized "My Tasks" dashboards where they receive immediate notifications for new project proposals.
- **Review Mechanics:** Reviewers assess technological alignments and submit detailed assessments. Decisions are recorded in the `project_approvals` table, preserving the history of who reviewed what, and when.

### Phase 3: Project Gate Reviews & EAC Preparation
- **Prepare for EAC:** Projects approved in BTA are automatically routed to the EAC preparation stage, ensuring all artifacts and prerequisites are gathered before the executive committee meets.
- **EAC Committee Meeting Workspace:** 
  - Features real-time dynamic governance checklists.
  - Interactive transcript notes.
  - Ability to digitally capture the final EAC alignment, effectively bringing the executive outcome into a secure audit log.

### Phase 4: PIP / PIC Validation (Post-Implementation/Project Investment Committee)
- Transition capabilities are securely laid out to flow projects out of EAC and into **PIC Review**, finalizing financial and investment governance validations.

## 3. Administrative Capabilities & Testing Enablers
To facilitate smooth deployments, demonstrations, and system testing, we designed powerful admin-exclusive capabilities:

- **Admin "Fast-Forward" Overrides (`fromAdminOverride`):**
  - Allows administrative users to instantly bypass standard inbox routing.
  - Can skip or transition projects seamlessly between BTA, EAC, and PIC stages.
  - **Success Screen Redirection:** Seamlessly channels overridden projects directly to success screens, bypassing normal team queues.
  - Fully hidden from standard business users to maintain strict integrity in production.

## 4. Architectural Enhancements

### Frontend (User Interface & Experience)
- **Design Overhaul:** Completely reimagined the visual baseline to a premium design system featuring dynamic micro-animations, glassmorphism, responsive navigation, and strict color tokens.
- **Modular Domains:** Clear feature partitioning: `intake/`, `bta-review/`, `eac-review/`, `gate-review/`, `team-inbox/`, etc.

### Backend (Database & State Persistence)
- **Sequential Approval Flow Database Schema:** 
  - `projects` table tracks standard current variables (lifecycle state, exact owner role).
  - `project_approvals` table decoupled from standard project details to strictly track governance decisions (stage history, dates, author).
- **Core APIs Developed:** 
  - `/approvals/pending` API: Pushes real-time tasks to respective front-end dashboards.
  - `/submit-decision` API engine: Dictates safe, validated movement of state transitions, ensuring robust role-access logic.
